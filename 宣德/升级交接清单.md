# 青花瓷 → 宣德 站点主题升级交接清单

> 适用对象：当前以独立 CSS 形式接入青花瓷主题（`青花瓷/qinghua.css`）的站点。
> 目标：替换为宣德主题（`宣德/xuande.css`），十分钟内完成，可随时回滚。

## 一、交付物

| 文件 | 说明 |
|---|---|
| `宣德/xuande.css` | 宣德主题完整独立 CSS（1532 行，含变量 / 基础覆盖 / 等级色还原 / 装饰层） |
| `宣德/README.md` | 宣德主题接入说明与特性 |
| `宣德/升级交接清单.md` | 本文件 |

## 二、升级步骤（三选一，与青花瓷接入方式一致）

1. **主题目录替换**：`themes/qinghua/qinghua.css` → 放入 `themes/xuande/xuande.css`，后台把可选项名称从「青花瓷」改为「宣德」；原目录可保留（并存为两个可选皮肤）。
2. **页头 link 替换**：
   ```html
   <!-- 旧 -->
   <link rel="stylesheet" href="/themes/qinghua/qinghua.css">
   <!-- 新 -->
   <link rel="stylesheet" href="/themes/xuande/xuande.css">
   ```
3. **用户自定义样式**：整体粘贴 `xuande.css` 内容替换原 `qinghua.css` 内容。

**唯一硬性前提不变：加载顺序在站点 main.css 之后**（宣德 CSS 与青花瓷同级特异性，靠顺序取胜，无 `!important` 滥用）。

把 link / 主题注册指回 `qinghua.css` 即可——两版**变量与基础层完全相同**，仅装饰层差异，无任何数据或结构变更，即换即回。

## 六、注意事项

1. **动效兼容**：流光（mask 动画）与开光 hover 需要现代浏览器（Chrome / Edge / Firefox 近年版本）；用户系统开启「减少动态效果」时流光自动静止，仅保留莲花与光点的静态微亮。
2. **无开关**：扩展版可在 popup 关闭流光；独立 CSS 版流光常开（受 reduced-motion 约束）。若站点需要关闭，删除 `xuande.css` 中 `#site_nav::before` 规则块（注释「釉下流光」段）即可。
3. **图片资源**：分类图 / 促销角标仍不参与换色（与青花瓷版边界一致）。
4. 提取来源：浏览器扩展「瓷之器」v1.4.0（2026-10-18）；后续扩展升级宣德时，重跑 `tools/extract_xuande.py` 可再生成同步版本。
