# 宣德 · 站点主题（独立版）

提取自浏览器扩展「瓷之器」的宣德主题（青花瓷的工艺纵深版），单文件纯 CSS。无 JS、无外部资源、无网络请求。

## 文件

| 文件 | 说明 |
|---|---|
| `xuande.css` | 完整主题（变量 + 基础覆盖 + 等级色还原 + 宣德装饰层） |

## 接入方式（三选一，前提都是**加载顺序在 main.css 之后**）

1. **NexusPHP 主题目录**：放入 `themes/xuande/`，后台注册为可选样式。
2. **页头直连**：main.css 的 `<link>` 之后追加 `<link rel="stylesheet" href="/themes/xuande/xuande.css">`。
3. **用户自定义样式**：用户直接粘贴文件内容。

## 与青花瓷（独立版）的差异

- 纹样从纯勾线升级为**分水**（莲头/花头/锦地内填淡彩，四档浓淡）
- 表头辅纹从卷草改为**缠枝莲**（主辅同源）+ **苏麻离青铁锈斑**；nav 深底为**锡光斑**
- 表格行 hover 为**开光**样式（白瓷提亮 + 描青围合）
- 返回顶部为**青花莲瓣钮**（默认青地白莲，hover 白瓷地青莲）
- nav 有**釉下流光**动效（8s 一轮，reduced-motion 自动静止；独立版无开关，扩展版可在 popup 关闭）

## 已知边界

- 流光与开光动效需要现代浏览器（Chrome / Edge / Firefox 近年版本）；`prefers-reduced-motion` 用户自动静止
- mask 动画（流光）在极旧浏览器下不显示，仅保留微亮底，无布局影响
- 图片资源（分类图 / 促销角标）不参与换色
