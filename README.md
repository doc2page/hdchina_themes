# 瓷之器

为 HDWinG（hdwing.org，NexusPHP 架构）新增界面主题的 Chrome 扩展。站点原生只有 Classic 一种风格，本扩展在不改动站点任何文件的前提下，通过内容脚本注入完整的主题样式层。仅作用于 hdwing.org。

## 功能

- **4 套基础主题**：暗夜（灰蓝深色）、Nord、纸墨（暖米护眼浅色）、松烟（墨绿深色）
- **青花瓷深度定制主题**：白地青花，瓷韵入屏——绢帛锦地暗纹、釉面高光、口沿弦纹、开光式导航激活窗、影青表头、描青瓷钮、矾红点睛
- **梅子青深度定制主题**：龙泉青瓷，温润如玉——纹样全凭釉层厚薄「显色」：篦划纹锦地（篦子划出的同心弧线组）、nav 两行错相水波带、表头篦纹辅带、弦纹分隔、莲瓣器足、玉瓷钮、铁足赭点睛
- **胭脂红深度定制主题**：宫廷粉彩，红金相彰——冷调胭脂为地、哑光暗金只做描线：金团花锦地、缎面柔光、如意云头纹带、描金开光导航、金莲瓣收边
- **曜变深度定制主题**：建盏油滴，幽光曜金——SVG 椭圆油滴锦地（三层虹彩：蓝青晕/银环/亮核，聚散成组 + 紫虹斑）、nav 兔毫竖纹（含金毫）、header/nav 金口沿包边、曜斑题饰、黑釉金环盏形圆钮；亮金严限口沿线与焦点
- **陶土深度定制主题**：粗陶野兽派（Neo-brutalism）——粗黑边框、无模糊硬阴影、直角、砖红 #a94b3d + 墨绿 #315044 + 米黄三色对撞：红条标题、按压式按钮（active 位移吞阴影）、墨绿 nav/表头红底线
- **哥窑深度定制主题**：开片青釉 × 复古终端——8px 网格底纹如哥窑开片（金丝铁线），半透明纸层浮于网格之上；苔绿主线、荧光绿 #9bbc0f 激活点睛（nav/分页/选区），控件 Courier 等宽、聚焦绿影
- **深色文字精修**：对原站 243 条 color 声明逐条映射——黑字、中灰、深蓝链接、暗红警示全部按主题重着色；用户等级色（Uploader/VIP/Moderator 等 20 级）在深色主题下统一亮化，身份语言保留、对比度 ≥ 4.5:1；内联 `style` 色用 `!important` 属性选择器接管
- **跟随系统**：系统深色模式开启时自动套用「暗夜」，浅色时恢复原版
- **即时切换**：popup 里点选即生效于所有已打开的站点页面，无需刷新
- **无闪白**：样式在 `document_start` 注入，首帧前就位
- **自定义 CSS**：追加在主题之后的个人样式，支持 `--hdw-*` 主题变量，停止输入自动保存

## 安装（开发者模式）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `hdwing-theme-plus/`
4. 打开 hdwing.org，点扩展图标选择主题

## 目录结构

```
hdwing-theme-plus/
├── manifest.json          # MV3 清单
├── shared/themes.js       # 10 套主题的 CSS 变量定义（内容脚本与页面共用）
├── content/core.css       # 核心覆盖样式，全部以 html.hdw-on 前缀作用域化
├── content/theme.js       # 变量注入 / 类开关 / storage 与系统深色监听
├── popup/                 # 主题选择弹窗
├── options/               # 设置页（主题 / 自定义 CSS）
├── tools/                 # 深度定制装饰层生成脚本（改纹样后重跑）
└── icons/
```

## 实现说明

- 主题 = 一组 `--hdw-*` CSS 自定义属性（`shared/themes.js`），核心样式 `content/core.css` 只引用变量。新增主题只需在 `themes.js` 里加一组变量。
- 深度定制主题可携带专属装饰层：注入器在 `<html>` 上加 `hdw-t-<id>` 类（如青花瓷的 `hdw-t-qinghua`），`core.css` 中以该前缀书写纹样 / 渐变 / 造型规则，与基础变量层叠加生效。
- `tools/` 是装饰层的单一来源：纹样以 Python 函数生成 URL 编码的 inline SVG data-URI，改纹样后重跑脚本重写 `core.css`（顺序固定：先 `build_qinghua_css.py` 后 `build_themes_css.py`，前者会截断其后区块）。`preview_patterns.py` 渲染纹样预览页并 headless Chrome 截图，供视觉评审通过后再写入。
- `core.css` 由 manifest 声明注入、永久存在于页面，启用与否由 `<html>` 上的 `hdw-on` 类控制——这就是「零闪白 + 免刷新切换」的实现基础。
- 覆盖样式基于对站点 main.css 的逆向映射（选择器 → 原色 → 变量），原样式中带 `!important` 的行级背景（置顶行、斑马纹等）在覆盖层中同步使用。
- 促销行（免费 / 2xFree / 50% 等）的底色按主题重新调度但保留色相，折扣状态依然一眼可辨。
- 暗色主题下站点 logo 以 `invert() + hue-rotate(180°)` 反色保证可读；若你的 logo 反色后不理想，可在自定义 CSS 里写 `.site_logo { filter: none !important; }` 关闭。

## 主题定制速查

自定义 CSS 中可直接引用主题变量，例如：

```css
/* 放大种子名 */
.torrent_list td.t_name table.tbname h3 { font-size: 15px; }

/* 用主题强调色染链接 */
a:hover { color: var(--hdw-link-hover); }

/* 隐藏公告区 */
.announcebox { display: none; }
```

## 已知边界

- 站点部分图标（分类图、促销角标、回到顶部按钮）为图片资源，不参与换色；深色主题下个别浅底图标观感一般，属图片资源限制。
- 首页 header 的背景原图被渐变替代；logo 反色滤镜是通用解法，不同 logo 效果可能有差异。
- 「原版」模式仅停用主题层，自定义 CSS 仍会注入（可在设置页清空）。
