HDWinG / NexusPHP 界面主题扩展 · 四款基础 + 青花瓷深度定制 · 即时切换

选择一套界面主题。切换即时生效于所有已打开的站点页面，无需刷新。

追加在所有主题之后的自定义样式，可用来微调任意细节。保存后立即生效，无需刷新站点页面。

可用主题变量参考 --hdw-*

主题颜色以 CSS 变量注入 :root，自定义 CSS 中可直接引用，例如 color: var(--hdw-accent)。常用变量：

  • --hdw-page 页面底色 · --hdw-outer 内容外框 · --hdw-content 正文底
  • --hdw-panel / --hdw-panel-2 面板与表头
  • --hdw-row / --hdw-row-alt / --hdw-row-hover 数据行三态
  • --hdw-text / --hdw-text-soft 文字层级
  • --hdw-link / --hdw-link-hover / --hdw-accent 链接与强调色
  • --hdw-input / --hdw-btn 表单与按钮底色
  • --hdw-free / --hdw-twoupfree 等促销行底色
